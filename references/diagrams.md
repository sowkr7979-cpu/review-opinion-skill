# 도해 패턴 카탈로그

모든 SVG는 `<figure><figcaption><b>그림 §.</b> 제목 <span class="muted">· 보조 설명</span></figcaption><svg viewBox="0 0 720 H" role="img" aria-label="…">…</svg></figure>`.
`figure svg{width:100%;height:auto}` 이므로 가로 720 기준으로 그린다. 글자 크기 7.6~11. 모든 `rect/circle`에 fill 명시. 화살표는 `<defs><marker id="arX" …>` 하나를 그림마다 정의(id 중복 주의).
**SVG `<text>` 안에는 HTML(`<sup>`, `<a>`, `<b>`)을 넣지 않는다.** 각주·링크는 figcaption에.

## 좌표 관례
- 막대 스케일은 캡션 또는 `<!-- x = 60 + 억×0.95 -->` 주석으로 남긴다.
- 발산 막대: 0선 x=520(2패널) 또는 x=330(1패널), 양수 오른쪽 초록 `#3F9C35`, 음수 왼쪽 빨강 `#C0392B`, 라벨은 막대 끝 바깥 6px.
- 값 라벨 색은 잉크(`#1f2224`), 계열색을 글자에 쓰지 않는다.
- 초록+빨강은 적록색약 ΔE 6.0(경계) → 부호(+/−)·라벨을 반드시 함께.

## HTML 부품(도해 대용)
- `.steps` 5칸 단계 체인, `.tiles3` 3칸 타일(`bad`=빨간 윗선, `good`=초록 윗선+연초록, `neu`=파란 윗선), `.je` 분개 카드(`.jh` 머리: 좌 제목/우 보조), `.jgrid` 2열.
- 표는 `.tw > table > caption "표 §."`, 헤더 회색 배경+초록 윗선, 짝수 행 옅은 회색.
