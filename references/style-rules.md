# 문체·표기·분량 규칙

검토의견서에 적용하는 문체·표기·분량 규칙이다.

## 문체
- 의뢰회사 제출용이므로 **존댓말 서술체**: "~합니다", "~하셔야 합니다", "~하시기 바랍니다". 내부 요약(핵심문제점 카드형)만 개조식 "~임/~음".
- 결론 박스(`.concl`): 첫 문장 = 결론(굵게 핵심어), 둘째 문장 = 근거 문단과 이유. 세 문장 이상이면 나눈다.
- **의문형 금지**: 제목·표 항목·플로차트에 "~인가/~는가/~할 것인가/~할까"를 쓰지 않는다. → "○○의 인식 여부", "○○의 크기와 유불리", "○○ 여부".
- 영어 약어·개발 용어 금지(NCI → 비지배지분, FV → 공정가치, PPA → 매수가격배분). 기준서 명칭은 "기업회계기준서 제○○○○호" 또는 "제○○○○호".
- 근거 표기: "제○○○○호 문단 N", 여러 문단은 "문단 11·16·19", 범위는 "문단 39~40", 항은 "문단 12(8)㈎".

## 분량
- 장마다 `결론 박스 1 + 도해 1~2 + 표 0~1 + 문단 1~2(각 1~2문장) + 타일 0~1줄 + 각주 상자`.
- 세 가지 이상 나열 → `.tiles3` 3칸 타일(제목 한 줄 + 본문 두 줄).
- "읽는 법", "유의점" 같은 불릿은 각 **한 문장**. 길어지면 도해로 옮긴다.
- 비유는 한 타일 또는 한 문장.
- 25쪽 안팎이 상한 감각.

## 각주
- 위치: 장 끝 `.fnbox`. 번호는 문서 전체 연번, 본문 표시는 `1)`.
- 항목 형식: `N) [링크: 기준서 제○○호 문단 N] — “원문 … ― 중략 ― … 원문”` 이어서 필요하면 한 줄 해설.
- 인용문은 **장식 없음**(굵게 X, 밑줄 X). 생략 표시는 "― 중략 ―"(전각 대시).
- 원문은 기준서 원문과 기준원 질의회신 본문에서 받은 텍스트만 발췌.
- 기준서에 정의가 없는 개념을 쓰면 각주에 "일반 원칙에 따랐다"고 밝힌다.

## 링크
- 본문의 모든 근거 규정을 링크. 기준서 `https://db.kasb.or.kr/s/{번호}`, 딥링크는 `kasb-links.json` 등록분만(`/s/{번호}/{섹션ID}`).
- 질의회신·해석위원회 결정·공개초안은 `www.kasb.or.kr/front/board/View{gubun}.do?siteCd=002000000000000&seq={seq}&...`.
- 공개 페이지가 없는 질의회신은 기준원 질의회신 요약 게시판(`allReplySummaryList.do`)으로 연결하고 본문에 그 사실을 적는다.
- kifrs.com 은 로그인이 필요하므로 링크 금지. db.kasb.or.kr 는 robots 금지이므로 자동 조회로 절 식별자를 알아내지 않는다.

## 금액·가정
- 제공받지 않은 수치는 "가정치"로 표시하고 표지 면책문과 표 캡션에 적는다.
- 단위는 "억원"·"주당 ○○원". 표는 `td.num`(우측 정렬·tabular-nums), 음수는 `−`(U+2212)와 `td.neg`, 양수 `+`와 `td.pos`.

## 디자인 토큰
- 서체 Noto Sans KR(→ Malgun Gothic), 본문 10.2pt / 1.72, 각주 8.1pt / 1.62.
- 색: navy `#00153D`(제목·표 헤더 글자), green `#3F9C35`(장 제목 밑줄·결론 박스·표지 줄), blue `#009CDE`(참고 박스·링크 강조), red `#C0392B`(주의 박스), amber `#E8A33D`(미해결·정책 선택), 회색 `#515356/#888B8D/#B8B8B9/#CDCECF/#F0F0F0`.
- 판정 셀: ✓ 초록 / △ 주황 / ✗ 빨강. 판정에는 색과 기호를 함께.
- 인쇄: A4, 여백 20/17/18/17mm, `.cover` 높이 245mm(인쇄), 표지 제외 쪽머리 로고+남색선, 쪽밑 초록선+문서명+쪽번호.

## 산출물
- HTML · PDF · Word 세 형식을 항상 함께. 파일명은 `주제_검토의견서_v3_YYYY-MM-DD.html`, `주제_검토의견서v3.pdf/.docx`. 추가본은 `_추가본`.
- 보고 메시지: 반영 내용 → 파일 표 → 유의점(가정치·미확인 링크).
